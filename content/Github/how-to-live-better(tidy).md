**睡眠与节律**
1. 睡前1小时不看发光屏幕。
2. 下午困就睡10分钟，不睡半小时。
3. 每天步行1小时；每晚睡约7小时；作息固定、固定起床。
4. 14点后不喝咖啡。
**运动与久坐**
5. 每周150–300分钟中等强度运动，快走即可。
6. 每周30–60分钟力量训练。
7. 别连续久坐，隔一阵起身动一动。
**饮食与体重**
8. 盐换低钠盐（钾盐）。
9. 每天一小把坚果。
10. 部分红肉换鱼禽。
11. 部分精米白面换全谷物。
12. BMI控在20–25
13. 喝烧开自来水，不常年买瓶装水。
农夫山泉4升4桶共24.7块2.1升8桶28块,怡宝5升4桶25块(平均一天3~4块/2升)
14. 不为“增强免疫力”逼自己洗冷水澡。
**工作与注意力**
1.  一次只做一件事。
2.  开放式办公室用耳塞，或找安静房间做需记忆的活。
3.  每周工作不超49小时。
4.  反复回想同一糟心事时，换件需要动手的事。
**人际与情绪**
1.  减少消耗你的人际关系，学会拒绝不想接的请求。
2.  生气先离场，把对方当天气，不当敌人。
**居住与消费**
1.  选住处优先通勤时长，缩短单程通勤。
2.  健身房按次/短周期付费，除非有一年以上稳定记录。
3.  大额非必需购买设24小时冷静期，网购善用七日无理由退货。
4.  住吃压到最低：合租月租代替日租，自炊/助餐食堂代替外卖。
**医疗与应急**
1.  优先选通过一致性评价的仿制药和集采中选药。
2.  手机丢了：挂失SIM卡、远程锁定、改密码、报警、冻结银行卡。
3.  伤残鉴定等治疗终结后再做，做早等级可能评低。
**重大决策**
1.  深夜不做重大决定。
2.  变故后头三个月，不可逆大决定一律往后推。
