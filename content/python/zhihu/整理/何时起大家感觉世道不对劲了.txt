世道何时开始不对劲？这问题如同问一只温水煮青蛙："你何时感觉水烫了？"
青蛙会说："刚开始还挺舒服的。"
有人说，“2025年刚开头，中国经济好像突然不行了”。“突然”这个词很有意思——就像一个人得了慢性病，直到某天倒下才“突然”发现自己病了。
但病，从来不是突然的。
有句妙语：“世道变坏，是从不让人说话开始的。”
这让我想起一个寓言：
村里有个人，嗓门特别大。
村长觉得吵，就让他小声点。
他小声了。
村长还是觉得吵，就让他用气音。
他用气音了。
村长还是觉得吵，就让他比划。
他比划了。
村长还是觉得碍眼，就让他闭眼。
最后，村里安静了。
安静得像墓地。
有人问："世道何时变坏的？"
答："从第一次让他小声点开始。"
苏轼1079年的遭遇，不过是这个寓言的宋朝版本。而今天，我们有了升级版——不是不让说，是让你“理性”地说、“正能量”地说、“建设性”地说，说到最后，你发现能说的只剩下“今天天气真好”。
但天气真的好吗？
经济学家们在争论数字，老百姓在感受温度。
就像有人说的，经济靡不振，忧心忡忡的领导人使出了浑身解数。
浑身解数是什么？
* 把失业叫"灵活就业"
* 把降薪叫"共克时艰"
* 把裁员叫"优化结构"
* 把倒闭叫"转型升级"
语言的魔术很高明，但肚子不会被话术填饱。
2015年："新常态"（你要适应）
2018年："贸易战"（外部因素）
2020年："疫情"（不可抗力）
2023年："复苏"（请再等等）
2025年："突然不行了"（终于装不下去了）
有趣的是，每代人都有自己的"世道不对劲"时刻：
50后说：是从上山下乡开始的
60后说：是从某个春夏之交开始的
70后说：是从下岗潮开始的
80后说：是从房价飙升开始的
90后说：是从996开始的
00后说：是从一出生开始的
每个人都觉得自己那一代最惨，但其实是接力赛——上一代传下来的"不对劲"，加上这一代新增的"不对劲"，传给下一代。
如同病毒变异，一代比一代毒。
为什么人们"突然"感觉不对劲？不是世道突然变坏，而是装睡的成本突然变高。
以前：
装睡 = 还能混日子
清醒 = 惹麻烦
现在：
装睡 = 连日子都混不下去了
清醒 = 反正都是麻烦，不如清醒
当装睡的收益小于装睡的成本时，人们就会"突然"醒来，"突然"发现世道不对劲。
这就是2025年的"突然"——不是经济突然崩了，是装不下去了。
有人提到"螺旋下落"，这个词很准确。
不是直线下坠（那太难看），而是螺旋（还能假装是在盘旋上升）。每转一圈，都觉得是在前进，其实是在下沉。
第一圈：这是战略调整
第二圈：这是必要阵痛
第三圈：这是最后一次
第四圈：这是新的开始
第五圈：这是...（已经没人信了）
有人问，“我们开始陷入了道德困境，怎么选，发现都不对？”
答案是：当系统本身就是错的时候。
说真话 = 找死
说假话 = 恶心
不说话 = 同谋
工作 = 被剥削
不工作 = 活不下去
创业 = 给自己挖坑
结婚 = 负担不起
不结婚 = 对不起父母
离婚 = 伤害孩子
生孩子 = 养不起
不生孩子 = 断了香火
生二胎 = 找死
这不是选择题，是送命题。
历史不会重复，但会押韵。
1966-1976：不许思考
1989：不许聚集
2025：不许悲观
从不许思考到不许悲观，这是进步还是退步？
或许都不是，只是换了个韵脚，内核没变——不许。
所以，世道何时开始不对劲？
悲观者说：从来就没对劲过
乐观者说：马上就要对劲了
现实者说：问这个问题时就不对劲了
智者说：能问出来就说明还没彻底不对劲
但我想说：
世道不对劲，不是从某个时刻开始的，而是一个渐进的过程。就像视力衰退，你不知道从哪天开始看不清，只知道某天发现，原来清晰的世界已经模糊。
而最可怕的不是世道不对- 劲，是大家都假装没有不对劲，直到装不下去的那天，"突然"发现——
原来我们一直在下沉，只是螺旋让我们产生了上升的错觉。
青蛙问哲学家："我什么时候该跳出去？"
哲学家说："当你开始问这个问题的时候。"
青蛙说："可是已经跳不动了。"
哲学家说："那就是上一次问的时候。"
