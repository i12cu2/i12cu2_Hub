**Hyper Time Manager System** 是一款专为 Unreal Engine 5.5 设计的时间管理模块，提供对游戏内时间的全面控制。

该系统将时间权威存储在 **GameState** 中，确保所有依赖时间的系统（如 NPC 日程、昼夜循环、世界事件）保持完美同步。

### 1. 中央时间权威（GameState Time Authority）
- 时间数据存储在 **GameState** 中，所有系统通过绑定该权威源保持同步
- 多人游戏环境下自动复制，保证客户端与服务器时间一致

### 2. 交互式时间操控
- 支持玩家通过交互对象（如床、篝火）跳过时间或推进到指定时刻
- 提升游戏节奏与沉浸感，适用于休息、等待等机制

### 3. 系统集成能力
- 提供灵活的事件分发器（dispatchers），可轻松连接至您自己的系统：
  - 昼夜循环切换
  - NPC 行为日程
  - 环境状态变化（如灯光、天气）
  - 任务触发条件

### 4. 高级时间管理
- **非线性时间线**：支持自定义时间曲线，实现非均匀时间流速
- **自定义时间刻度**：全局或局部调整时间流逝速度
- **动态日程**：基于时间触发事件或状态变更

### 5. 时区支持
- 为世界中的不同区域分配独立时区
- 增强真实感或创造玩法差异（如跨时区任务）

### 6. 完全蓝图、模块化、多人就绪
- 100% 蓝图实现，无需 C++ 即可修改和扩展
- 组件化设计，可按需添加到 Pawn、GameMode 或 GameState
- 内置网络复制支持

| 场景              | 应用方式                                        |
| ----------------- | ----------------------------------------------- |
| **昼夜循环**      | 绑定时间到天空球光照强度、颜色，自动过渡        |
| **NPC 作息**      | 根据时间切换 NPC 行为树状态（工作、休息、巡逻） |
| **商店营业**      | 仅在一定时间范围内开放交互                      |
| **任务触发**      | 在特定时间点激活任务或过场动画                  |
| **时间旅行/跳跃** | 通过交互物直接推进时间到指定时刻                |
| **时区差异**      | 不同地图区域拥有独立时间偏移                    |
