V3升级到V4的核心内容可以总结为以下三大板块：

1. 底层架构与基础设施的重构（核心骨架变了）

事件管理器：引入基于Gameplay Tags的统一事件系统，系统间通过“标签+数据”解耦通信，不再硬连接。

容器化库存：库存从“纯槽位”升级为可嵌套、可存在于世界中、可注入逻辑（如弹匣）的容器结构。

大世界与性能优化：针对World Partition验证，引入对象池（减少高频生成开销）、保存过滤（避免存无效数据）、减少不必要的Tick和UI刷新。

项目结构与UI：统一了命名规范，UI全面重做，并推出了可复用的通用径向菜单（替代硬编码菜单）。

2. 现有核心系统的深度功能增强（旧系统变强了）

能力与属性：重构为基于Gameplay Tags，支持传染性状态效果。

地图系统：支持区域集成，采用分层加载（概览低分辨率，缩放切高精度瓦片），大幅提升大世界地图性能。

全局保存：增加保存过滤机制，流式大世界下更安全。

网格转Actor：重写保存/加载，完美支持World Partition和PCG程序化生成。

语音管理器：完全重写，支持基于Pawn的多角色语音自动匹配（如男女声变体）。

视觉小说：增加视频支持和首玩选项。

建筑/战斗/装备：适配容器库存，命中处理更清晰，稳定性提升。

3. 海量全新系统的正式引入（新增30+个模块）
V4正式将以下新系统纳入生态（部分作为独立模块，但架构已集成）：

AI与生态：基于StateTree的NPC框架（日常/感知/战斗）、同伴系统（驯服指令）、坐骑系统、区域管理器。

多人组织：团队系统（敌友判定）、权限系统（门禁/访问）、公会管理器。

生存与交互：检查系统（3D预览/文档）、可掠夺尸体、剥皮系统、尸体分解、埋藏储物、数据库系统、3D角色预览器。

战斗与防御：原始防御（陷阱）、现代防御（炮塔/机枪/导弹）、安保系统（摄像头/激光）、武器挂载系统（可视化改装）。

工厂自动化：完整的传送带、机器、电力、电池、网络分发、资源采集与生产链系统（与容器库存和权限深度集成）。

特别提示（来自官方警告）：
官方明确建议正在生产的项目不要立即从V3迁移到V4，且严禁混用V3和V4系统，需等待V4全生态稳定后再进行迁移。

**简单白话以及相关项目**

第一句（广播台模式）
以前各个系统（比如背包和任务）是直接打电话联系，乱了就容易出bug。现在变成了一个“广播台”，谁喊一句口号（标签），谁想听就听，这样系统之间不会互相干扰，出问题也好查。
Hyper Event Manager v4 https://www.fab.com/listings/de25d8cd-4389-4e4a-bce6-0c76e3d59e61

第二句（背包变俄罗斯套娃）
以前背包只能放东西。现在背包可以套背包，还能把一个背包直接扔在地上当箱子用，甚至可以把弹匣插进枪里，玩法逻辑活了很多。
Hyper Inventory System v4（Fab 暂未上架独立页面，集成于 MST Pro V4 中）

第三句（游戏越做越大，优化了“偷懒”机制）
地图特别大的时候，以前电脑全都要算，会很卡。现在远处的怪物和树木会自己“休眠”不动，打斗时的火花特效也不反复生成新物体，而是重复利用旧特效，省性能。
Hyper Object Pooler：https://www.fab.com/listings/190185e3-c014-4fca-b64e-f0f3af85a7f5
Hyper Player Proximity Manager：（Fab 暂未上架独立页面，集成于 MST Pro V4 中）

第四句（旧地图变聪明了，像手机地图一样放大缩小）
以前看大世界地图要么模糊，要么卡死。现在地图变高清智能了，你缩小看时用低清图，放大看细节时自动切成高清小块，不会再糊成一团。
Hyper Map System v4（Fab 暂未上架独立页面，集成于 MST Pro V4 中）

第五句（保存系统不再“无脑”存垃圾数据）
以前你路过一棵树，它也会存一次记录，导致存档越来越大。现在它会过滤，只有你真正砍了树或做了关键动作，它才存，这样存档更安全、不容易坏档。
Hyper Global Save System：https://www.fab.com/listings/08e40e79-11e8-4a40-9fc1-93bc8f6a9d3e

第六句（角色说话的声音能自动变男女了）
以前配音很死板。现在系统会根据你操控的角色（比如男角色或女角色）自动匹配对应的嗓音，不用手动调来调去。
Hyper Voice Manager v4（Fab 暂未上架独立页面，集成于 MST Pro V4 中）

第七句（新增了像《宝可梦》那样的“宠物系统”）
你可以把怪物打晕、喂食、驯服它，让它跟着你打架或者干活，驯服后还能收进类似精灵球的空间里。
Hyper Companion & Taming System v4 https://www.fab.com/listings/f5350cc8-46b2-4056-9f2c-e58c10328b01

第八句（新增了像《我的世界》那样的“自动化工厂”）
加了传送带、发电机和自动挖矿机，你可以搭建流水线，让机器自己生产东西，不用手搓。
Hyper Factory Systems v4（Fab 暂未上架独立页面）

第九句（新增了可以放哨的“自动炮塔”）
不止有陷阱，还能造机枪、火焰喷射器、甚至跟踪导弹的炮塔来自动防御基地。
Hyper Turret Defense System v4 https://www.fab.com/listings/ef1e9fc3-4e79-495b-9d4f-fd5f7b4a46ba

第十句（NPC不再是傻子，有了“日常起居”）
敌人或村民不再站着发呆，他们会巡逻、感知周围动静、饿了吃饭或者起内讧打架，行为更像真人。
Hyper Routine-driven NPC Framework v4 https://www.fab.com/listings/0065f6c6-c61e-44ba-a361-25e41c0c490a

第十一句（多了“扒皮”和“尸体分解”）
打死动物或敌人后，不只是掉个袋子，你可以直接互动扒皮割肉，而且尸体会慢慢腐烂、长蛆，视觉效果更真实。
Hyper Skinning System v4 https://www.fab.com/listings/588ee980-dd3a-43dd-804c-55370ee0d979

**总结**

V3是功能堆叠的生存模板；V4重构为事件驱动、容器化库存、大世界优化的模块化平台，并新增AI生态（NPC/宠物/坐骑）、自动化工厂、防御塔、公会团队权限、剥皮分解、3D预览等30+系统。官方警告生产项目勿急迁移，勿混用。
