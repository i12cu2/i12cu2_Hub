## 四、迭代变化总结

- **冰系**：旧核心是爆冰诀、连续冰爆、冰渊爆、封霜劲、寒天劲、昆仑圣影/烨霜；中期莲系加入绽灵莲、元素莲生；红砂6.0变成 **元素星陨 + 烈元诀 + 元素奔涌[冰] + 爆冰诀 + 连续冰爆/冰渊爆/冰环破 + 惊雷十劫/苍龙破**。
- **毒系**：旧核心是祛毒、瘴煞、蚀骨春、沼生、苍牙；中期加入瘴蚀莲生、绽灵莲；天绝加入舍元劲、三才汇聚、四灵归极、御气仙壶；红砂6.0变成 **元素星陨 + 烈元诀 + 元素奔涌[毒] + 淬毒术 + 沼生 + 蚀骨春/瘴煞 + 惊雷十劫**。
- **电系**：旧核心是召雷剑、驭电术、玄雷术、掣电术、振天雷、召雷术、抗雷术、夺魂、魂燃一线、反噬；中后期加入御电奔雷、元素奔涌[电]、舍元劲；红砂6.0变成 **元素星陨 + 烈元诀 + 元素奔涌[电] + 游雷振 + 御电奔雷 + 掣电术 + 振天雷**。
- **火系**：旧核心是焚燃、烈烬、四象猛火、游龙步、四象燃刃、铜皮、焚天术；后来主要融入蒸体系，核心变为 **焚燃 + 游龙步 + 电系组件**。
- **莲/合道体系**：中期核心是绽灵莲、元素莲生、强振莲生、瘴蚀莲生；天绝核心是舍元劲、三才汇聚、四灵归极、御气仙壶、含光宝炉、汇灵幡[奔涌]。

**一句话总结**：  
后期最不可替代的是 **元素星陨、烈元诀、元素奔涌**；单元素里冰看 **爆冰诀/连续冰爆**，毒看 **沼生/淬毒术/蚀骨春**，电看 **掣电术/振天雷/御电奔雷**，火蒸看 **焚燃/游龙步**，莲系看 **绽灵莲/元素莲生**，天绝看 **舍元劲**。
