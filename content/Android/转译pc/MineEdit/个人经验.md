# 报错分析

1.
Microsoft Visual C++ Runtime - 需要安装微软运行库 -> 依赖组件 vcredist2022

2.
this application cannot run under a Virtual Machine - 游戏无法在虚拟运行 -> proton9.0-x64-2问题 -> 兼容层设置wine9.5

3.
Make sure you have DirectX 11 installed -> GPU驱动没选对 或者 -> 启动参数"-force-gfx-direct"(启动单线程)

4.
Microsoft Visual C++ 2015-2022 Redistributable (arm64) -> 组件依赖 vcredist2022

# Winlator 特配

GPU图形驱动程序 (用最新的,如果图形出错,调回上一个版本)
```
Turnip (骁龙) 似乎能开dx12 8g3及以下用25.0.0-r11 轮着测试帧率
    flushall版本用于调试测试
Vortek (骁龙8e,天玑)
VirGL (通用 -> 天玑/麒麟等)
Adreno/系统驱动 (天玑/麒麟只能选此)
```

DXVK版本/图形加速 (DirectX 9/10/11)
```
DXVK (DX转Vulkan 骁龙)
    天玑只能用DXVK1.10.3以下里例如1.7.2
     骁龙随意,推荐1.10.3-async/2.3.1-async/2.6.1-async
WineD3d (DX转OpenGL 通用 -> 天玑/麒麟等)
VKD3D (DX12程序)
CNC DDraw (兼容老游戏)
```
