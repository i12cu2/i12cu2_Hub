### 蛋白质摄入建议

| 项目   | 建议                                   |
| :----- | :------------------------------------- |
| 高蛋白 | 有利于减脂，不会涨脂肪                 |
| 餐次   | 正常一日三餐补充蛋白即可，不必强行多餐 |
| 不运动 | 每天 1g/kg 蛋白质（最低要求）          |
| 长身体 | 1.5~2.2g/kg，摄入更多也没问题          |
| 安全量 | 3.5g/kg 安全                           |

### 训练与恢复

| 项目       | 说明                                               |
| :--------- | :------------------------------------------------- |
| 膝伤       | 动作不规范会膝伤，举重不会膝伤                     |
| 伤膝活动   | 跑跳和骑车伤膝                                     |
| 腰酸       | 跟硬拉没有关系                                     |
| 停练两个月 | 会掉一小部分肌肉，但影响不大，但不能长时间躺在床上 |
| 维持肌肉   | 作极限重量的30%量可以维持肌肉，但一定会降低力量    |
| 恢复速度   | 会比退步速度快得多（不超过三个月）                 |
| 训练时间   | 按照自身习惯即可                                   |
| 禁欲       | 对增肌并无很强关联，释放50min后会疲劳，2h后恢复    |
| 上科技     | 容易变老，全身爆痘                                 |

### 睡眠与睾酮

| 项目       | 说明                                                                                                   |
| :--------- | :----------------------------------------------------------------------------------------------------- |
| 睡眠       | 最好12点睡，7~9小时，尽量满8小时                                                                       |
| 睾酮与脱发 | 睾酮过低过高都容易脱发                                                                                 |
| 低睾酮     | 容易生气，减脂困难                                                                                     |
| 睾酮与情绪 | 影响情绪不大（青少年暴躁是因为情绪化问题）；高睾酮更自信更坚定；超出医用计量会出现超强攻击性和自杀倾向 |
| 运动量     | 每周两天，每天5组，技术力竭，花样少一点                                                                |
| 睾酮作用   | 增加肌肉，降低脂肪，增加骨密度，提高自信和红细胞个数                                                   |
| 睡眠不足   | 4.5小时以下：睾酮降低，脾气暴躁，注意力不集中，健忘，情绪低落，增肥，掉肌肉掉力量，恢复慢              |
| 饮食       | 少吃豆制品（植物蛋白），多肉蛋奶                                                                       |
| 每周运动   | 至少中等强度运动（心率120，70%）150~300min，或高强度运动（心率140，80%）75~150min                      |
| 最大心率   | 220-年龄                                                                                               |
