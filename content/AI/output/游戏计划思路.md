# 《多世界·元素武器·自由构筑》设计草案 v0.1

## 一、一句话定位

一款以 **多世界探索、元素与攻击方式解耦、武器自由切换、六人小队、PVE/PVP 并存** 为核心的动作抽卡养成 RPG。

核心循环：

> 探索/解密/日常 → 获得钻石、金币、材料 → 抽卡与养成 → 打副本/PVP → 获得装备与突破材料 → 进入更高难度副本/新世界。

---

## 二、经济与货币

| 货币 | 来源 | 主要用途 | 备注 |
|---|---|---|---|
| 金币 | 副本、怪物、日常 | 角色升级、突破 | 基础养成货币 |
| 钻石 | 解密、探索、活动、日常 | 抽卡 | 可免费获取，核心抽卡货币 |
| 点券 | 付费 | 皮肤、外观、通行证、便利道具 | 建议不直接卖战力，避免破坏平衡 |

建议原则：

- 金币：副本大量产出，用于角色等级/突破。
- 钻石：探索和活动产出，用于抽卡。
- 点券：付费货币，主要卖皮肤、外观、特效、通行证、背包便利等。
- 材料背包无限大，自动拾取，减少整理负担。

---

## 三、世界观与开放结构

### 1. 剧情与 NPC 城

- 主线围绕“移民”展开：不同文明、不同世界的人被迁移/汇聚到多世界体系。
- NPC 城地图不可修改，类似传统剧情城镇。
- 不同世界可有不同风格：埃及风、中国风、蒸汽风、魔法风、科技枪械风等。
- 剧情城主要用于：主线推进、NPC 交互、城内解密、商店、任务。

### 2. 资源探索世界

- 玩家可选择若干“主世界/资源星球”。
- 每个世界资源可见、有限、可采集。
- 世界可抛弃，但抛弃后选择新世界有内置 CD。
- 资源世界可以联机：
  - 访问其他玩家的资源世界。
  - 与玩家一起探索副本。
- 资源世界可设计日常任务、采集、解密、随机事件。

### 3. 解密结构

解密可分三类：

1. 一次性单人闯关副本：一次性奖励，偏机关、解谜、剧情。
2. NPC 城市内解密：与剧情、NPC、场景互动结合。
3. 资源世界日常任务：可重复，偏探索、采集、护送、调查。

### 4. “开放”体现在哪

不是传统无缝大世界，而是：

- 多世界选择与资源状态变化。
- 武器、元素、攻击方式自由组合。
- 联机访问他人世界。
- 解密路径和副本打法多样。
- NPC 城不可改，但资源世界可探索、可消耗、可替换。
- 不同世界有不同文明、规则、科技水平。

## 四、角色、队伍与职业定位

### 1. 队伍规模

- 六单位一队。
- 支持单人、双人、三人游玩。
- 人数不足时可用 AI/机器人补位。
- 匹配前预先分配位置，再进入匹配。
- 推荐配置：3 输出、1 防御、2 奶妈。

### 2. 大技能分配

全队共有 6 个大技能槽，按玩家人数平均分配：

| 玩家人数 | 每人控制单位 | 大技能分配 |
|---|---|---|
| 单人 | 6 | 6 个 |
| 双人 | 各 3 | 每人 3 个 |
| 三人 | 各 2 | 每人 2 个 |
| 满编六人 | 各 1 | 每人 1 个 |

这样既保留六人队策略，又适应不同人数。

### 3. 武器类型与基础定位

| 定位 | 武器类型 |
|---|---|
| 物理输出 | 弓、长枪/矛、剑、钝器/棍、刀 |
| 法器输出 | 法书、法杖 |
| 防御 | 剑盾、大盾 |
| 治疗 | 盾奶、血奶 |
| 扩展 | 枪械：手枪、步枪、机枪等 |

基础职业可按武器类型划分为约 12 种。  
但建议不要做“死职业”，而是：

> 角色 + 武器 + 元素 + 装备 + 技能 = 实际战斗职业。

例如：

- 剑 + 火元素 + 流血词条 = 火系持续输出。
- 棍 + 雷元素 + 击晕词条 = 雷系控制。
- 法书 + 冰元素 + 回能装备 = 冰系辅助/控制。
- 枪械 + 法术附魔 + 配件 = 法术机关枪。

### 4. 职业与装备联系

- 护甲类型可影响定位倾向，但不建议硬锁。
- 布甲、皮甲、板甲、重甲、轻甲提供不同加成。
- 角色可有“护甲熟练”，穿非熟练护甲时收益降低或消耗增加。
- 武器决定普攻/战技模组，装备决定数值和词条，角色决定天赋和大招。

### 5. 技能与人物关系

建议拆成四层：

| 来源 | 作用 |
|---|---|
| 角色 | 天赋、被动、大招、专属机制 |
| 武器 | 普攻模组、战技、攻击方式 |
| 元素 | 属性伤害、克制、减伤、附加效果 |
| 装备 | 主属性、词条、套装效果 |

这样“人”和“武器”不会互相抢戏，而是组合出 Build。

## 五、战斗系统

### 1. 核心原则

- 攻击方式与元素属性无关。
- 可切换武器。
- 不同武器有不同攻击方式。
- 元素可自由选择或通过武器/角色绑定。
- 六单位一队，战斗强调配队、职责、元素克制和操作。

### 2. 属性克制

- 属性克制：加伤 20%。
- 同属性：减伤 50%。
- 多种自然属性可设定为：火、水、风、雷、土、冰、光、暗等，具体待定。

### 3. 物理攻击方式与异常

| 武器 | 攻击方式 | 可能效果 |
|---|---|---|
| 棍/钝器 | 打击、击晕 | 眩晕、破甲、打断 |
| 剑 | 劈砍、刺击 | 流血、多级伤残 |
| 刀 | 斩击、连斩 | 流血、破防 |
| 长枪/矛 | 刺击、突进 | 贯穿、击退 |
| 弓 | 远程射击 | 弱点、标记 |
| 法书/法杖 | 施法 | 元素附加、范围效果 |
| 剑盾/大盾 | 格挡、盾击 | 防御、嘲讽、眩晕 |
| 盾奶/血奶 | 护盾/治疗 | 回复、护盾、净化 |

物理异常建议：

- 击晕：短时间无法行动。
- 流血：持续掉血。
- 多级伤残：可设计为不同层数，降低移速、攻速、防御或命中。
- 钝器偏控制/破甲，利器偏流血/伤残。

### 4. 特殊武器

- **物理学圣剑：撬棍**
  - 彩蛋武器。
  - 高击晕、高破甲、高暴击，或对机械/门/箱子有特殊效果。
  - 可做专属成就、隐藏任务、抽象派表演副本奖励。

### 5. 枪械扩展

可加入科技世界：

- 枪械有配件槽。
- 配件可附魔。
- 附魔可改变伤害类型、弹道、射速、元素效果。
- 可实现“法术机关枪”：枪械 + 法术附魔 + 配件系统。
- 枪械与法术需要平衡：弹药、过热、回能、配件成本等。

## 六、装备与成长

### 1. 装备来源

建议三轨并行：

1. 副本掉落。
2. 玩家制造。
3. 兑换/活动获取。

避免纯随机掉落，也避免纯制造导致副本失去意义。

### 2. 护甲类型

| 护甲 | 主要加成 |
|---|---|
| 布甲 | 法术施法速度 |
| 皮甲 | 物理攻击速度 |
| 板甲 | 魔法防御、物理韧劲 |
| 重甲 | 物理防御、魔法抗性 |
| 轻甲 | 通用均衡 |

### 3. 部位主属性

| 部位 | 主属性 |
|---|---|
| 上衣 | 血量最大值 |
| 下装 | 回能效率 |
| 护手 | 回避、命中 |
| 头部 | 暴击、暴击伤害 |
| 脚部 | 施放速度、攻速、移速 |

### 4. 装备强化与词条

- 装备最高 5 级/5 阶段。
- 每提升一级：
  - 提升主属性。
  - 从词条中获得一次增幅。
- 词条可包括：攻击、防御、元素伤害、元素抗性、暴击、回能、施法速度、攻速等。
- 套装效果分 2/3/4/5 件：
  - 2 件：小效果。
  - 3 件：核心机制。
  - 4 件：强化机制。
  - 5 件：完整流派。

## 七、抽卡系统

### 1. 货币与来源

- 钻石通过探索世界、活动、日常、解密获得。
- 抽卡有保底。
- 抽卡不会重复。
- 十连必出四星。
- 重复/低星转化：
  - 三星 + 四星 → 兑换材料。
  - 四星 + 五星 → 兑换材料。
  - 五星/五星突破材料。

### 2. 建议卡池结构

可区分：

- 角色池。
- 武器池。
- 外观/皮肤池，用点券或活动货币。

如果“不重复”针对角色，则抽满后转为突破材料或兑换币。  
如果针对武器，则需设计武器图鉴与精炼系统。

### 3. 设计目的

- 降低重复挫败。
- 保证十连体验。
- 让低星也有兑换价值。
- 让五星突破材料成为长期目标。

---

## 八、PVE 副本

- 支持单人、双人、三人。
- 六单位一队，AI 补位。
- 副本体力按时间回复，可累积。
- 匹配前预先分配位置：输出、防御、奶妈。
- 推荐配置：3 输出、1 防御、2 奶。
- 可建立房间：单人 + 机器人。
- 匹配限制：副本战斗力水准。
- 副本产出：
  - 装备。
  - 角色突破材料。
  - 金币。
  - 抽卡兑换材料。
  - 特殊外观/彩蛋。
- 副本类型可包括：
  - 装备成长副本。
  - 剧情副本。
  - 解密副本。
  - 抽象派表演/创意副本。
  - 联机共斗副本。

---

## 九、PVP 系统

- 根据实力分段。
- 十局认证赛。
- 赛季评分：
  - 前期：胜加，败不减。
  - 达到一定分数/段位后：胜加，败减。
  - 根据赛季参与场次给予评分保护或奖励。
- PVP 可设计为：
  - 公平数值模式。
  - 装备生效模式。
  - 或两者分开。
- 需要重点平衡：元素克制、同属性减伤、六人队职责、枪械与法术。

---

## 十、玩家成长与等级限制

玩家力量强弱建议体现在：

1. 角色等级与突破。
2. 装备品质、强化、词条、套装。
3. 技能等级。
4. 武器类型与武器练度。
5. 元素克制与队伍搭配。
6. 操作与切换武器熟练度。
7. 世界等级/副本战力门槛。

等级限制建议：

- 账号等级：解锁功能、副本、世界。
- 角色等级：基础战力。
- 世界等级：影响资源世界掉落和敌人强度。
- 副本战力门槛：防止跨级匹配。
- 不建议用“职业”直接决定强弱，职业只是定位。

## 十一、创新点与开放点总结

可以提炼为以下卖点：

1. **元素与攻击方式解耦**：武器决定动作，元素决定属性，自由组合。
2. **多世界有限资源**：资源可见、可枯竭、可抛弃、有冷却。
3. **联机访问玩家世界**：资源世界 + 副本共斗双联机。
4. **六人队大技能分配**：单人 6 个，双人各 3，三人各 2。
5. **物理异常系统**：击晕、流血、多级伤残，钝器/利器差异明显。
6. **枪械配件 + 附魔 + 法术机关枪**：科技与魔法融合。
7. **抽卡不重复 + 保底 + 兑换**：降低重复挫败。
8. **NPC 城不可改 + 资源世界可探索**：剧情稳定，探索开放。
9. **撬棍物理学圣剑**：彩蛋、抽象、社区传播点。

同类型游戏中，单点可能已有，但你的优势在于“组合方式”和“多世界资源结构”。

## 十二、待确认问题

后续做详细设计前，建议先定这些：

1. 自然属性具体有哪几种？
2. 抽卡对象是角色、武器，还是两者都有？
3. “不重复”是角色不重复，还是所有卡池不重复？
4. 点券是否只卖皮肤，还是也卖便利/通行证？
5. 职业是硬职业，还是武器类型 + 定位？
6. 装备是副本掉落为主，还是制造为主？
7. PVP 是否装备生效？
8. 资源世界是否会被其他玩家掠夺或消耗？
9. 枪械世界是独立世界，还是全游戏通用？
10. 六人队中，玩家是控制 1 个角色还是多个角色？
