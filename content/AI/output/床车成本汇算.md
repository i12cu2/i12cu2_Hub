# 1. 车型需求与筛选

## 1.1 硬性需求

目前只考虑比亚迪。

- **必须纯电**：增程、油车、混动皆不考虑。
- **预算**：30 万以内。
- **车型**：SUV。
- **电池续航与充电速度要好**：至少 70 度电。
- **床车能力**：后二排、三排可改装成床，目标尺寸约 **1.7m × 0.8m**，身高能睡。
- **颜色**：银灰、白色。

## 1.2 加分项

- 座椅舒适，最好真皮，主副驾真皮。
- **AR-HUD**：大加分项。
- **车内 220V 插座**：大加分项。
- **后轮转向**：大加分项。

# 2. 租房 vs 住车经济模型

## 2.1 早期问题与待补全项

原始问题：小吴去杭州工作，有两个选项：

1. 杭州当地租房：一室一厅或合租，估计 3000 元/月。
2. 住比亚迪牌子的车里。

共同假设：

- 吃饭都下馆子不变，平均每天 28 元成本。
- 洗衣服：租房用洗衣机；住车每月开两次钟点房洗，80 元/次。
- 夏天空调正常开，冬天用电热毯。
- 租房没钱买车，因此打车，按 0.8 元/公里。
- 睡车里以电耗 0.6 元/度计算。
- 每年总通勤距离为 `n` 公里，未知，以表达式表达。
- 停车费 300 元/月。
- 喝水都是瓶装水，每天 1 升，另外 1 升在公司喝。
- 开满八年之后出现事故，无责任有保险，汽车残值转化为本金。
- 租房平均一年搬家一次，每次搬家 400 元。
- 第一年要算上整个购车成本。
- 第一年全款买车，一次性付清，没有贷款和利息。
- 八年后完整八年过去，然后出事故。
- 搬家按一次性 400 元粗算。

后续调整：

- 两个方案都买一个电动自行车来通勤，车 900 元一次性购入。
- 住车里每天通勤距离 2 公里。
- 租房每天通勤距离 10 公里。
- 房租 + 物业费价格变为 `x`，未知价格。
- 往返总距离，以 250 工作日计算。
- 电动自行车以租房的电费计算，驻车以电车供电算电费。
- 不维护，用八年，残值 0，不修不换，简化计算。
- 打车暂且归零。
- `x` 是每个月的房租 + 物业费，其他另算。
- 停车附近不需要钱。

## 2.3 方案一：租房方案

### 第 1 年

- 衣：洗护洗衣计入租房水电，不单列。
- 食：下馆子 10,220 + 农夫山泉 1,460 = **11,680 元**。
- 住：房租物业 36,000 + 水电 2,400 + 搬家 800 = **39,200 元**。
- 行：电动自行车购车 **900 元**；充电已含在租房水电中。

**第 1 年合计：11,680 + 39,200 + 900 = 51,780 元**

### 第 2~8 年

每年结构相同，不再有电动自行车购车支出。

- 衣：0。
- 食：**11,680 元**。
- 住：**39,200 元**。
- 行：0，充电已含在水电中。

**第 2~8 年每年合计：11,680 + 39,200 = 50,880 元**

### 八年累计

> 51,780 + 50,880 × 7 = **407,940 元**

## 2.4 方案二：买车住车里方案

### 第 1 年

- 衣：健身房 1,688 + 钟点房洗衣 1,920 = **3,608 元**。
- 食：**11,680 元**。
- 住：购车 P + 交强险 950 + 三者险 1,500 + 保养 500 + 驻车空调 720 + 电热毯 26 = **P + 3,696 元**。
- 行：电动自行车购车 900 + 充电 7.2 = **907.2 元**。

**第 1 年合计：3,608 + 11,680 + P + 3,696 + 907.2 = P + 19,891.2 元**

### 第 2~7 年

每年结构相同。

- 衣：**3,608 元**。
- 食：**11,680 元**。
- 住：950 + 1,500 + 500 + 720 + 26 = **3,696 元**。
- 行：电动自行车充电 **7.2 元**。

**第 2~7 年每年合计：3,608 + 11,680 + 3,696 + 7.2 = 18,991.2 元**

### 第 8 年

- 衣：**3,608 元**。
- 食：**11,680 元**。
- 住：3,696 - 40,000 残值 = **-36,304 元**。
- 行：**7.2 元**。

**第 8 年合计：3,608 + 11,680 - 36,304 + 7.2 = -21,008.8 元**

### 八年累计

> 第 1 年：P + 19,891.2  
> 第 2~7 年：18,991.2 × 6 = 113,947.2  
> 第 8 年：-21,008.8  
> **八年累计 = P + 19,891.2 + 113,947.2 - 21,008.8 = P + 112,829.6 元**

## 2.6 追平点参考

两方案八年累计成本相等时：

> 407,940 = P + 112,829.6  
> **P = 295,110.4 元**

也就是说：

- 若比亚迪 SUV 落地价 **低于约 29.51 万元**，住车里方案八年累计更省；
- 若高于约 **29.51 万元**，租房方案更省。

# 3. 生活配套成本：洗衣、洗澡、健身、停车、充电

## 3.1 洗衣三方案成本测算

> 原文档按 `n` 为时间成本，元/小时，示例 `n=25`。  
> 地点：深圳，床车用户，电车。  
> 频率：每两周洗一次，攒两周衣服，约 8–10kg。  
> 方案二设备：3kg 直驱变频洗烘一体机，一次洗不完，需分 3 轮洗烘。  
> 电车能耗：0.20 元/公里。  
> 洗衣液：约 0.8 元/轮，3 轮 = 2.4 元。  
> 公厕补水：免费，但 70L 水箱不够 3 轮用，3 轮约需 120L，需补水 2 次。  
> 司机之家距离：推测单程约 10km，往返 20km。

### 三个方案

1. **酒店钟点房**：每两周去 2km 内酒店开钟点房，连续洗烘 3 轮。
2. **自购洗烘一体机**：3000 元洗烘机 + 200 元 70L 水箱 = 初始 3200 元；去 500m 内公厕补水，车内 220V 洗，分 3 轮。
3. **司机之家 / 加油站免费洗衣**：每两周周末 / 节假日去免费洗衣点，推测往返 20km，现场洗烘 3 轮。

### 方案一：酒店钟点房

- 直接现金：钟点房约 140 元 + 停车 5–10 元 = **145–150 元/次**。
- 耗时：往返 20 分钟 + 洗衣换桶整理约 4 小时 = **4.5 小时**。
- 时间成本：4.5n。
  - n=25 时：4.5 × 25 = **112.5 元**。
- 单次总成本：145–150 + 4.5n。
  - n=25 时：145–150 + 112.5 = **257.5–262.5 元**。
- 月成本：约 **515–525 元**。

### 方案二：自购 3kg 洗烘一体机 + 70L 水箱

- 初始投入：3000 + 200 = **3200 元**。
- 单次直接现金：
  - 电费：3 轮约 1.5 度 × 0.66 元/度 ≈ **1 元**。
  - 洗衣液：3 轮 × 0.8 = **2.4 元**。
  - 合计 = **3.4 元**。
- 补水体力/时间：2 次 × 约 30 分钟 = **1 小时** → 1n。
  - n=25 时：**25 元**。
- 洗衣有效时间：换桶、整理、看管约 **1.5 小时** → 1.5n。
  - n=25 时：**37.5 元**。
- 时间合计：2.5 小时 → 2.5n。
  - n=25 时：**62.5 元**。
- 单次总成本，不含折旧：3.4 + 2.5n。
  - n=25 时：3.4 + 62.5 = **65.9 元**。
- 折旧：3200 元按 3 年约 72 次摊销 ≈ **44.4 元/次**。
- 单次总成本，含折旧：3.4 + 2.5n + 44.4。
  - n=25 时：3.4 + 62.5 + 44.4 = **110.3 元**。
- 月成本：
  - 不含折旧：65.9 × 2 = **131.8 元**。
  - 含折旧：110.3 × 2 = **220.6 元**。
- 回本周期：对比方案一，约 **10–11 个月回本**。

### 方案三：司机之家 / 加油站免费洗衣

- 直接现金：往返 20km × 0.20 元/km = **4 元**，洗衣免费。
- 耗时：往返 50 分钟 + 现场等待 3 轮约 4 小时 = **4.83 小时**。
- 时间成本：4.83n。
  - n=25 时：4.83 × 25 ≈ **120.8 元**。
- 单次总成本：4 + 4.83n。
  - n=25 时：4 + 120.8 = **124.8 元**。
- 月成本：约 **249.6 元**。
- 若单程 15km，往返 30km，电费约 6 元，时间更长，单次总成本约 **137–146 元**。

### 洗衣总结

1. 长期常规使用：选方案二，自购 3kg 洗烘一体机最划算。建议长期用最好升级 100L 以上水箱，或换更大容量洗烘机。
2. 方案三适合顺路，不适合专门跑。免费洗衣听起来省钱，但往返 20km + 现场等 3 轮，时间成本约 120.8 元（n=25），专程去并不便宜。
3. 方案一酒店钟点房只建议应急。单次约 257.5–262.5 元，月约 515–525 元，成本最高，还要连续占用钟点房 4 小时以上。
4. 时间价值公式：时间成本 = 耗时 × n。若 n 变化，直接替换即可。电车费 = 公里数 × 每公里电费。

## 3.2 洗澡三方案成本测算

> 原文档按 `n` 为时间成本，元/小时，示例 `n=25`。  
> 地点：深圳宝安，床车用户，电车。  
> 频率：每 2 天一次，每月约 15 次。  
> 单次用水：约 15 升。  
> 电车能耗：0.20 元/公里。

### 三个方案

1. **健身房月卡**：办月卡，通勤往返共 10km，在健身房淋浴。
2. **70L 水箱 + 热得快 + 车外放电**：去厕所接水，用热得快加热，车外放电供电，在车内或车旁擦洗 / 冲洗。
3. **司机之家 / 营地洗澡**：去司机之家免费淋浴，或房车营地付费含淋浴。

### 方案一：健身房月卡洗澡

- 直接成本：
  - 月卡：宝安乐刻运动月卡约 **239 元/月**。
  - 电车通勤：往返 10km × 0.20 元/km = **2 元/次**。
- 时间成本：
  - 往返通勤：10km 市区路况，往返约 **30 分钟**。
  - 洗澡 + 更衣整理：约 **30 分钟**。
  - 单次耗时：约 **1 小时**。
  - 时间成本：1n = **25 元/次**。
- 单次总成本：2 + 1n = 2 + 25 = **27 元/次**。
- 月成本：月卡 239 + 通勤 2×15 + 时间 25×15 = 239 + 30 + 375 = **644 元/月**。
- 如果按年卡约 1799 元/年，约 150 元/月折算，月成本可降至约 **555 元/月**，但需一次性投入。

### 方案二：70L 水箱 + 热得快 + 车外放电

- 初始投入：
  - 热得快，带自动断电 / 温控：约 **40 元**。
  - 折叠水桶 20L：约 **30 元**。
  - 小淋浴泵 + 喷头：约 **50 元**。
  - 车载逆变器，1000W 以上纯正弦波：约 **300–500 元**，取中位数 **400 元**。
  - 合计初始投入：**约 520 元**。
- 单次直接成本：
  - 水费：公厕补水免费。
  - 电费：热得快约 1000–1500W，加热 15L 水从常温到 40°C 约需 15 分钟，耗电约 **0.3 度**。按 0.66 元/度，电费约 **0.2 元**。
  - 合计直接成本：**约 0.2 元/次**。
- 单次时间成本：
  - 补水：去 500m 内公厕，往返 + 接水约 **20 分钟**。
  - 加热：15 分钟，按有效占用 **10 分钟** 计。
  - 洗澡 + 收拾：约 **20 分钟**。
  - 总有效耗时：约 **50 分钟 ≈ 0.83 小时**。
  - 时间成本：0.83n = **20.8 元/次**。
- 单次总成本：0.2 + 0.83n = 0.2 + 20.8 = **21 元/次**。
- 月成本：15 × 21 = **315 元/月**。
- 含折旧：520 元按 3 年、每月 15 次共 540 次摊销 ≈ 0.96 元/次，含折旧单次约 **21.96 元**，月成本约 **329 元/月**。

### 方案三：司机之家 / 营地洗澡

- 司机之家：
  - 深圳宝安区有司机之家分布，提供免费淋浴间，全天候供应热水和沐浴露、洗发水。洗衣、淋浴均免费。
  - 距离推测：单程约 5–10km，往返 10–20km，取中位数往返 15km。
  - 时间：往返约 40 分钟 + 洗澡更衣 20 分钟 = 1 小时，时间成本 25 元。
  - 电车费：15km × 0.20 = **3 元**。
  - 单次总成本：3 + 1n = 3 + 25 = **28 元/次**。
  - 月成本：15 × 28 = **420 元/月**。
  - 关键问题：司机之家主要服务货车司机，私家床车用户可能被婉拒。
- 房车营地：
  - 深圳已指定 9 个正规房车停放点，停车费 20–600 元/天，含水电和淋浴。
  - 若仅洗澡，可能按营地日费收取，取中低档 50–100 元/天。
  - 若营地日费 50 元，电车费 3 元，单次总成本约 **78 元/次**，月成本约 **1170 元/月**。

### 洗澡总结

1. 长期常规使用：方案二，水箱 + 热得快，综合成本最低。单次约 21 元（n=25），月约 315–329 元，初始投入仅约 520 元，时间最灵活。对比健身房月卡，每月节省约 300 元以上，约 1.5–2 个月回本。
2. 方案一适合“洗澡 + 健身”双重需求。如果本来有健身习惯，239 元/月乐刻月卡可同时解决洗澡和锻炼。
3. 方案三适合“顺路碰运气”，不建议专门跑。司机之家淋浴免费且条件不错，但服务对象是货车司机，私家床车用户使用存在被拒风险。
4. 安全提醒：热得快必须完全没入水中再通电，建议买带温控和自动断电型号；车外放电需确认逆变器功率足够，1000W 以上纯正弦波；注意防水和漏电保护。
5. 合法性提醒：公厕少量取水用于个人清洁一般不会被干预；大量取水可能被劝阻。司机之家非货车司机使用前建议先确认是否开放。

# 6. 关键结论与决策建议

## 6.1 车型结论

- **大唐EV 950KM后驱激光雷达旗舰型**：
  - 最满足硬性需求和加分项。
  - 纯电、SUV、130 度电、950km、后轮转向、220V、Nappa 真皮、AR-HUD、7 座、空间大。
  - 含选装包约 **27.99 万元**，仍在 30 万以内。
  - 是床车改造潜力最大的一款。
- **宋Ultra EV 710KM卓越型**：
  - 价格最低，17.99 万元。
  - 电池 82.7 度，续航 710km，满足至少 70 度电。
  - 但无后轮转向、无车内 220V、仿皮、5 座，后二三排床车能力弱于大唐。
  - 适合预算优先、床车需求不极致的情况。
- **钛3 565KM四驱闪充版**：
  - 16.98 万元，四驱闪充，有 220V。
  - 但尺寸最小，轴距 2745mm，紧凑型，565km，电池 75.6 度。
  - 后二三排床车能力最弱，不适合作为长期床车主力。
  - 适合城市代步 + 偶尔车内休息。

## 6.2 经济结论

基于最终确认模型：

- 租房方案八年累计：**407,940 元**。
- 买车住车方案八年累计：**P + 112,829.6 元**。
- 追平购车价：**P = 295,110.4 元**。

因此：

- 若车落地价 **低于约 29.51 万元**，住车里方案八年累计更省。
- 若车落地价 **高于约 29.51 万元**，租房方案更省。
- 大唐EV 含选装约 27.99 万元，低于追平点，理论上住车方案更省。
- 但该结论高度依赖：停车是否免费、能否合法长期驻车、充电是否方便、洗澡洗衣实际成本、房租 x、残值 4 万、保险保养费用。

## 6.3 生活配套结论

- 洗衣：
  - 长期：自购 3kg 洗烘一体机最省，月约 131.8 元，含折旧约 220.6 元。
  - 应急：酒店钟点房，月约 515–525 元。
  - 顺路：司机之家，月约 249.6 元，但专程不划算。
- 洗澡：
  - 长期：70L 水箱 + 热得快 + 车外放电，月约 315–329 元。
  - 洗澡 + 健身：健身房月卡，月约 644 元；年卡折算约 555 元。
  - 顺路：司机之家，月约 420 元，但可能被婉拒。
- 停车与充电：
  - 最终模型按停车免费、驻车充电 0.6 元/度。
  - 若实际停车 300–700 元/月，经济模型会显著变化。
- 合法性与安全：
  - 长期驻车、过夜、外放电、公厕取水、司机之家使用资格，都需要提前确认。
  - 纯电车长期停放注意电量 40%–60%，定期唤醒补电。
